# Symbion Native Shell

Placeholder for the planned C++ Windows WebView2 host.

The first native milestone should be a thin shell around the existing Symbion FastAPI web UI. It should preserve the current look and feel, load the same local interface, and avoid changing Python backend behavior while WebView2 scaffolding matures.

See [../docs/WEBVIEW2_MIGRATION.md](../docs/WEBVIEW2_MIGRATION.md) for the phased migration plan.
